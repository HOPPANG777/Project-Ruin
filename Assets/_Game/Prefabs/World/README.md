# 이동 발판 배치 (기획자용)

Unity Hierarchy에서 **우클릭 → Project Ruin → 이동 발판**으로 배치합니다.
`Assets/_Game/Prefabs/World`의 프리팹을 맵으로 끌어 놓아도 됩니다.
플레이어가 발판의 이동 영역에 들어가면 자동으로 이동합니다. 상호작용 키는 필요 없습니다.

## 같은 맵 안에서 이동

1. **같은 맵 안에서 이동**을 배치합니다 (`PositionTransitionPad.prefab`).
2. 루트 오브젝트를 출발 위치로 옮깁니다.
3. Hierarchy에서 루트 아래 **도착 위치 (이 오브젝트를 옮기세요)**를 도착할 곳으로 옮깁니다.
   루트 Inspector의 **도착 위치 선택해서 옮기기** 버튼으로 선택할 수도 있습니다.
4. 맵을 저장합니다. 도착 위치는 처음부터 연결되어 있어 별도의 연결 작업이 없습니다.

파란 영역이 출발 발판, 파란 십자 표시가 도착 위치입니다. Scene 뷰의 **Gizmos**를 켜세요.
복제한 발판은 자신의 도착 위치를 사용합니다. 루트를 움직이면 자식 도착 위치도 함께 움직이므로,
출발 위치를 먼저 정한 뒤 도착 위치를 옮기세요. 도착 위치를 출발 발판 안이나 벽 안에 두지 마세요.
돌아오는 이동이 필요하면 발판을 하나 더 배치하고 목적지를 설정합니다.

## 다른 맵으로 이동

1. 목적지 맵을 열고, 도착할 곳에 **다른 맵에서 도착할 지점**을 배치합니다.
   Hierarchy 이름을 `동쪽 입구`처럼 구분하기 쉽게 바꾸고 맵을 저장합니다.
   메뉴로 배치하면 도착 지점 ID는 자동으로 만들어집니다.
   `TransitionSpawnPoint.prefab`을 직접 드래그했다면 Inspector의 **도착 지점 ID 만들기**를 누릅니다.
2. 출발 맵에서 **다른 맵으로 이동**을 배치합니다 (`SceneTransitionPad.prefab`).
3. 루트 Inspector의 **목적지 맵**에 목적지 Scene 파일을 넣습니다.
4. **목적지 맵 연결 (맵 목록에 자동 등록)**을 누릅니다.
   필요한 스테이지 번호, SceneCatalog의 STAGE 분류, 빌드 씬 목록을 자동으로 설정합니다.
5. **도착 지점** 목록에서 앞서 만든 지점을 선택하고 출발 맵을 저장합니다.

보라색 영역이 다른 맵 이동 발판, 초록 십자 표시가 다른 맵에서의 도착 지점입니다.
도착 지점을 선택하지 않으면 목적지 맵에 배치된 플레이어의 시작 위치를 사용합니다.
도착 지점을 복제하면 복제한 지점의 Inspector에서 **새 ID 만들기**를 누르세요.
기존 지점의 ID를 바꾸면 이를 사용하는 발판에서도 도착 지점을 다시 선택해야 합니다.
다른 씬에 같은 파일 이름을 사용하지 마세요.

## 영역과 표시

- 루트 Inspector의 **이동 영역 크기**로 발판을 밟는 범위를 조정합니다 (기본 1 × 1).
- **발판 표시 (아트 교체 가능)** 자식의 SpriteRenderer를 바꾸거나 자식을 삭제하여 표시를 교체할 수 있습니다.
  도착 위치와 도착 지점의 십자 표시는 편집용이며 게임 화면에는 나오지 않습니다.
- 경고가 보이면 Inspector에서 안내한 항목을 수정합니다. 연결된 도착 위치를 삭제했으면
  **도착 위치 만들고 연결하기**로 복구할 수 있습니다.
- 프리팹이 삭제되었다면 **Tools → Project Ruin → 이동 발판 → 기본 프리팹 만들기**로 다시 생성합니다.
  기존 프리팹은 덮어쓰지 않습니다.

## 개발자가 한 번 준비할 사항

정식 `GameRoot.prefab`의 씬 전환 서비스와 페이드가 초기화되어 있어야 합니다.
플레이어에는 `UnitPlayer`, `Rigidbody2D`, `Collider2D`가 필요합니다.
발판은 Default 레이어의 BoxCollider2D 트리거이며 플레이어와 충돌 감지가 허용되어야 합니다.
다른 맵 전환은 기존 StageFlow / SceneStateBridge 파이프라인을 사용하므로
목적지 맵에도 기존 게임의 플레이어 배치/생성 구성이 필요합니다.
새 맵의 시작/로드 구성 자체는 이 프리팹에서 생성하지 않습니다.
