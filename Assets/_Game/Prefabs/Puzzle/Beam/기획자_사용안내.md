# Beam 부품 배치 안내

Project 창에서 `Assets > _Game > Prefabs > Puzzle > Beam` 폴더를 엽니다.
필요한 프리팹을 맵의 Scene 창으로 끌어 놓고, **Hierarchy에서 배치한 부품을 선택**해 오른쪽 Inspector를 편집합니다.
프리팹 파일을 더블 클릭하면 공통 원본 편집 화면이 열립니다. 퍼즐마다 다른 ID와 각도는 맵에 배치한 부품에서 정하세요.

## 어떤 부품을 꺼내면 되나요?

| Project 창의 프리팹 파일 | 배치 후 이름 / 역할 | 사용 기준 |
| --- | --- | --- |
| Beam_관리자 | 부품 목록과 저장 담당 | 퍼즐마다 1개 |
| Beam_시작 기둥 | 빛을 내보내는 시작점 | 정확히 1개 |
| Beam_2방향 기둥 | 빛을 받아 1갈래로 출력 | 필요한 만큼 |
| Beam_4방향 기둥 | 빛을 받아 3갈래로 출력 | 필요한 만큼 |
| Beam_8방향 기둥 | 빛을 받아 7갈래로 출력 | 필요한 만큼 |
| Beam_끝 기둥 | 빛이 도착하면 완료 | 정확히 1개 |
| Beam_초기화 발판 | 밟으면 처음 상태로 복귀 | 최소 1개 |
| Beam_고정 장애물 | 이동과 광선 차단 | 선택 |
| Beam_출구 장애물 | 완료하면 사라져 통로 개방 | 선택 |
| Beam_밀 수 있는 돌 | 스킬로 밀어 경로 변경 | 선택 |
| Beam_부술 수 있는 벽 | 스킬로 부숴 경로 변경 | 선택 |
| Beam_광선 표시 | 관리자에 연결된 선 표시 원본 | 맵에 직접 배치할 필요 없음 |

2·4·8방향 이름에는 빛을 받는 쪽도 포함됩니다. 실제 출력은 각각 1·3·7개입니다.
전체 퍼즐을 설치하거나 부품을 자동 연결하는 버튼은 없습니다. 아래처럼 직접 배치하고 목록에 등록합니다.

## 1. 위치와 ID 정하기

1. 관리자, 시작·중간·끝 기둥, 초기화 발판을 맵에 배치합니다. 필요하면 장애물·돌·벽도 배치합니다.
2. Transform의 Position으로 위치를 정합니다. 기둥 몸체가 서로 겹치지 않도록 둡니다.
3. 관리자의 **퍼즐 저장 ID**를 `CH01_BEAM_01`처럼 정합니다. 같은 스테이지에서 관리자마다 다른 ID를 씁니다.
4. 기둥마다 **기둥 ID**를 정합니다. 예: `START`, `P01`, `P02`, `END`. 같은 관리자의 기둥끼리 중복되면 안 됩니다.
5. 돌은 **돌 ID**, 벽은 **벽 ID**를 정합니다. 예: `STONE01`, `WALL01`. 같은 관리자의 돌·벽 사이에서 중복되면 안 됩니다.

부품은 서로 다른 부모 아래에 두어도 됩니다. 같은 부모로 묶을 필요는 없습니다.
한 맵에 다른 Beam 퍼즐을 만들 때는 별도 관리자와 별도 부품을 배치합니다.
이미 사용 중인 저장 ID와 부품 ID를 바꾸면 기존 진행 저장과 연결되지 않습니다.

## 2. 관리자 목록에 직접 등록하기

Hierarchy에서 **Beam_관리자**를 선택합니다. 목록 왼쪽의 작은 삼각형을 눌러 펼칩니다.
**등록 수**에 사용할 개수를 입력하고, Hierarchy의 부품을 각 칸으로 끌어 넣습니다.

| 관리자 목록 | 끌어 넣을 대상 |
| --- | --- |
| 기둥 | 이 퍼즐의 시작·중간·끝 기둥 루트 전부 |
| 초기화 발판 | 이 퍼즐의 초기화 발판 루트 |
| 밀 수 있는 돌 | 이 퍼즐의 돌 루트 |
| 부술 수 있는 벽 | 이 퍼즐의 벽 루트 |
| 고정 장애물 | 이 퍼즐의 고정 장애물 루트. Collider2D가 선택됩니다. |
| 출구 장애물 | 완료하면 사라질 출구 장애물 루트 |

선택 부품을 사용하지 않으면 등록 수를 **0**으로 둡니다. 각 부품은 한 칸에 한 번만 등록합니다.
Project 창의 공통 원본 대신 **Hierarchy에 배치한 부품**을 등록하세요.
등록 순서는 자유롭고, 같은 부품을 다른 관리자의 목록에 함께 넣으면 오류가 표시됩니다.

출구에는 통로를 막는 장애물만 넣습니다. 관리자나 다른 부품을 포함한 부모를 넣으면 완료 때 함께 꺼집니다.
등록을 마치면 관리자 아래의 빨간 오류 안내를 확인하고, **부품 연결과 저장 ID 확인 완료**가 표시되도록 고칩니다.

## 3. 기둥 방향 정하기

기둥을 선택해 **처음 바라보는 각도**를 정합니다. Transform의 Z 회전 대신 이 값을 사용하세요.

| 각도 | 방향 |
| --- | --- |
| 0° | 오른쪽 → |
| 90° | 위 ↑ |
| 180° | 왼쪽 ← |
| 270° | 아래 ↓ |

**플레이어가 회전 가능**이 켜져 있으면, 기존 상호작용 입력을 한 번 누를 때마다 **한 번 누르면 시계방향** 값만큼 회전합니다. 기본값은 45°입니다.
예를 들어 처음 90°인 기둥은 첫 입력에 45°, 다음 입력에 0°가 됩니다. 입력을 계속 누르고 있어도 반복 회전하지 않습니다.
시작·끝 기둥은 기본 고정이고, 중간 기둥은 기본 회전 가능합니다.

**출력 N의 추가 각도**는 기둥 방향에 더하는 값입니다. 기둥 방향이 90°이고 출력 각도가 0°라면 위로, 출력 각도가 90°라면 왼쪽으로 나갑니다.
4·8방향 기둥의 각 출력은 독립적으로 정할 수 있습니다. 출력 간격을 같게 맞출 필요는 없습니다.
표시된 화살표로 방향을 확인하세요. 빛을 받으면 기둥이 이 화살표 방향으로 빛을 내보냅니다.

## 처음 만들어 볼 작은 퍼즐

플레이어가 이동 가능한 빈 공간에서 다음 부품을 직접 배치해 볼 수 있습니다. 기존 맵 좌표에 맞춰 모두 같은 거리만큼 옮겨도 됩니다.

| 부품 | Position X, Y | ID | 처음 바라보는 각도 | 출력 추가 각도 |
| --- | --- | --- | --- | --- |
| 시작 기둥 | 0, 0 | START | 0° | 0° |
| 2방향 기둥 | 2, 0 | P01 | 90° | 0° |
| 끝 기둥 | 4, 0 | END | 0° | 없음 |
| 초기화 발판 | -2, -2 | 없음 | 해당 없음 | 해당 없음 |
| 출구 장애물 (선택) | 6, 0 | 없음 | 해당 없음 | 해당 없음 |

1. 별도 관리자를 배치하고 새 퍼즐 저장 ID를 정합니다.
2. 기둥 등록 수를 3으로 정하고 시작·2방향·끝 기둥을 직접 등록합니다.
3. 초기화 발판 등록 수를 1로 정하고 발판을 등록합니다. 출구를 쓴다면 출구 장애물에도 등록합니다.
4. 2방향 기둥의 회전 단위는 45°로 둡니다. 관리자에서 오류가 없는지 확인한 뒤 씬을 저장합니다 (`Ctrl+S`).
5. Play에서 2방향 기둥에 접근해 기존 상호작용 입력을 한 번 누릅니다. 45° 방향으로 회전하며 광선이 켜집니다.
6. 이때 초기화 발판을 밟으면 90°로 복귀하고 광선이 꺼집니다.
7. 기둥을 다시 두 번 누르면 오른쪽으로 이어져 끝 기둥에 도달합니다. 출구가 열리고 추가 조작과 초기화가 잠깁니다.

Play를 멈춘 뒤 기획 설정을 편집하세요. Play 중 편집한 씬 설정은 종료 시 원래대로 돌아옵니다.

## 그림과 광선 모양 바꾸기

- 기둥: 루트 Inspector의 **몸체 그림**, **화살표 그림 (모든 출력)**에 Sprite 에셋을 끌어 넣습니다. 화살표는 오른쪽을 향하는 그림을 씁니다.
- 초기화 발판·돌·벽: 루트 Inspector의 **발판 그림**, **돌 몸체 그림**, **벽 그림**에서 교체합니다.
- 고정·출구 장애물: Hierarchy에서 루트 왼쪽 삼각형을 펼쳐 **장애물 그림** 또는 **출구 그림** 자식을 선택합니다. SpriteRenderer의 **Sprite**를 교체합니다.
- 출력별 화살표: 기둥 아래 **방향 표시 > 출력 화살표 N** 자식의 Sprite를 각각 교체합니다.
- 돌의 장식: **장식 표시 > 장식 그림** 자식을 편집합니다. 몸체 그림 교체와 별도입니다.
- 그림 크기: 그림 자식의 Transform Scale로 조정합니다. 몸체와 접근 감지 범위를 변경해야 할 때는 담당 개발자와 충돌 범위를 확인하세요.
- 광선: 관리자에서 **광선 모양과 길이**를 펼쳐 색상·굵기·최대 길이·표시 순서를 정합니다.
- 기둥 색상: **연결 표시 색상**에서 빛을 받기 전·후 색상을 정합니다.

공통 그림을 모든 새 배치 부품에 쓰려면 Project 창의 프리팹 원본에서 교체합니다. 특정 맵 부품만 바꾸려면 Hierarchy의 배치 부품을 편집합니다.
**고급** 항목에는 충돌체·출력 개수·머티리얼 관련 참조가 있습니다. 기본 프리팹은 연결되어 있으므로 일반 배치에는 기본값을 사용합니다.

## 문제가 생겼을 때

| 증상 | 확인할 항목 |
| --- | --- |
| 관리자가 빨간 오류를 표시함 | 안내에 적힌 목록·ID·시작/끝 개수를 수정합니다. |
| 기둥에 다가가도 회전하지 않음 | 관리자 기둥 목록에 배치한 기둥이 있는지, 회전 가능이 켜져 있는지, 완료 상태인지 확인합니다. |
| 처음에 광선이 안 보임 | 초기에는 꺼져 있습니다. 회전 가능한 기둥을 처음 조작하면 켜집니다. |
| 빛이 중간에서 멈춤 | 화살표 방향, 광선 최대 길이, 기둥 사이의 돌·벽·장애물을 확인합니다. |
| 발판을 밟아도 초기화되지 않음 | 관리자 발판 목록에 등록했는지 확인합니다. 완료 후에는 초기화되지 않습니다. 발판에서 나갔다 다시 들어가야 다시 작동합니다. |
| 돌·벽을 조작할 수 없음 | 필요한 스킬을 플레이어가 획득했는지 확인합니다. 스킬 등록·획득은 기존 게임 흐름을 사용합니다. |
| Play를 시작하자 이미 완료되어 있음 | 같은 저장 ID의 완료 기록이 있을 수 있습니다. 연습용 퍼즐에는 새로운 저장 ID를 씁니다. |

입력·플레이어·스킬·저장 연결을 점검해야 한다면 담당 개발자에게 같은 폴더의 `README.md`를 전달하세요.
메뉴 `Tools > Project Ruin > Beam > 현재 맵 설정 검증`은 오류 확인만 하며 부품을 배치하거나 연결하지 않습니다.
