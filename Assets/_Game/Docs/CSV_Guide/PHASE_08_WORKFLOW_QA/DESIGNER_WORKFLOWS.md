# 디자이너 작업 흐름

## 1. 공통 흐름

1. 변경 목적과 영향을 받는 시스템을 적는다.
2. [교차 참조 지도](../PHASE_07_REFERENCE/CROSS_REFERENCE_MAP.md)로 부모를 먼저 확인한다.
3. 기존 ID/키를 재사용할 수 있는지 검색한다.
4. 새 행을 부모 CSV부터 추가한다.
5. 각 CSV 전용 가이드의 헤더·CodeList·예시를 대조한다.
6. 자동 검증을 통과시킨다.
7. 관련 장면에서 정상/경계/실패 흐름을 플레이한다.
8. 저장 후 재로드를 확인한다.
9. 리뷰 시 변경한 ID와 영향 파일을 함께 전달한다.

## 2. 새 아이템

1. 이름/설명 키를 로컬라이제이션에 등록한다.
2. 아이템 ID, 가격, 판매 여부, 유형, 최대 스택을 정한다.
3. 선택적 아이콘 ID의 카탈로그 경고를 확인한다.
4. 지급·소비·상점 참조를 추가한다.
5. 인벤토리 추가/스택/판매/저장을 확인한다.

## 3. 새 대화

1. 배우와 초상화를 만든다.
2. 그래프 ID와 시작 노드를 정한다.
3. 모든 본문/선택지 문구를 로컬라이제이션에 등록한다.
4. 노드를 만든 뒤 `next_node_id`를 연결한다.
5. 선택지가 있는 노드의 노드 `next_node_id`는 비운다.
6. 액션별 `action_id`/다음 노드 규칙을 적용한다.
7. NPC 기본 바인딩과 상태 라우트를 추가한다.
8. 모든 분기와 종료를 플레이한다.

## 4. 새 퀘스트

1. 퀘스트 제목/설명과 목표/보상 설명을 등록한다.
2. 퀘스트 상위 행을 만든다.
3. 목표에 실제 게임플레이가 설정할 대문자 플래그를 연결한다.
4. 보상 쌍을 완전하게 작성한다.
5. 제출 아이템이 있으면 소비 행을 만든다.
6. 수락/갱신/완료/보상 대화 액션을 연결한다.
7. NPC 상태 라우트를 작성한다.
8. 소비 없음/있음 각각의 완료 흐름과 저장을 확인한다.

## 5. 새 퍼즐

1. 마스터에 종류와 크기를 등록한다.
2. 종류별 상세 가이드대로 모든 행을 작성한다.
3. PIPE는 방향표와 START/END, LIGHT는 타일 생성과 함께 생기는 클릭×영향 체크리스트와 가독성 보드, CIRCLE은 장면 프리팹 배열을 확인한다.
4. 구조 자동 검증을 통과시킨다.
5. 초기 표시, 조작, 해결 가능성, 클리어 이벤트를 PlayMode로 확인한다.

## 6. 새 상점

1. `can_sell=false` 통화 아이템을 만든다.
2. 상점과 판매 가능한 양수 가격 상품을 등록한다.
3. 최초 재고가 유한 수량임을 확인한다.
4. `OPEN_SHOP` 선택지를 연결한다.
5. `GameDataController`의 선택 TextAsset 연결을 확인한다.
6. 구매, 판매, 품절, 저장/재로드를 확인한다.

## 7. 리뷰 전달 템플릿

```text
변경 목적:
추가/변경한 주 ID:
변경 CSV:
영향받는 참조:
자동 검증 결과:
PlayMode 확인 장면/시나리오:
저장 호환성 판단:
남은 수동 확인:
```
