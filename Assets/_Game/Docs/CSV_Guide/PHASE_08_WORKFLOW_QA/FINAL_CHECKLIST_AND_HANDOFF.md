# 최종 체크리스트 및 인수인계

## 1. 작성자 체크

- [ ] 변경 목적과 대상 CSV가 명확하다.
- [ ] 정확한 헤더/열 순서를 유지했다.
- [ ] 필수 셀이 채워졌다.
- [ ] 시스템 ID, 로컬라이제이션 키, Boolean 형식이 맞다.
- [ ] CodeList 철자와 대소문자가 정확하다.
- [ ] 숫자 범위와 부모 내부 순서 중복을 확인했다.
- [ ] 모든 부모/자식/조건부 참조가 존재한다.
- [ ] 조건부 열 쌍과 대화 액션 규칙이 완전하다.
- [ ] 변경한 ID의 전체 사용처를 검색했다.

## 2. 시스템별 체크

### 로컬라이제이션/아이템

- [ ] `ko`가 비어 있거나 공백뿐이지 않다.
- [ ] 모든 표시 키가 존재한다.
- [ ] 판매 가능 아이템은 양수 가격이다.
- [ ] 최대 스택은 1 이상이다.

### 대화

- [ ] 그래프 시작 노드와 모든 next가 같은 그래프에 존재한다.
- [ ] 초상화가 해석된 배우에 속한다.
- [ ] 선택지가 있는 노드의 노드 next가 비었다.
- [ ] 액션별 action ID/next 규칙을 지켰다.
- [ ] 모든 분기와 종료를 플레이했다.

### 퀘스트/NPC

- [ ] 목표/보상/소비 순서와 ID가 부모 범위에서 유일하다.
- [ ] 진행 플래그가 현재 대문자 시스템 ID 계약을 따른다.
- [ ] 소비 아이템이 있는 완료/수령 흐름을 확인했다.
- [ ] NPC 라우트가 기본 바인딩을 가진다.
- [ ] 네 퀘스트 상태와 기본 폴백을 확인했다.

### 퍼즐

- [ ] 종류와 크기가 일치한다.
- [ ] PIPE/LIGHT는 전 좌표가 정확히 한 번 있다.
- [ ] PIPE의 START/END와 현재 회전표를 확인했다.
- [ ] LIGHT의 모든 타일에 클릭×영향 체크리스트 행과 열이 있고, 읽기용 보드 및 `|` 자동 생성 미리보기와 일치한다.
- [ ] CIRCLE 순서와 Unity 패턴 배열 범위를 확인했다.
- [ ] 해결 가능성과 클리어 이벤트를 직접 확인했다.

### 상점

- [ ] 통화는 판매 불가 아이템이다.
- [ ] 상품은 통화와 다르고 판매 가능/양수 가격이다.
- [ ] `initial_stock=0`을 무한으로 해석하지 않았다.
- [ ] 선택 TextAsset 연결과 `OPEN_SHOP` 흐름을 확인했다.

### 기술·도감

- [ ] 기술 기여도 합계와 마지막 재건 단계가 100이다.
- [ ] 도감 카테고리와 ItemType 또는 Technology 원본이 일치한다.
- [ ] 술 도감 항목에 재료가 한 개 이상 있다.
- [ ] 최초 획득 후 아이템 수량이 0이 되어도 발견 상태가 유지된다.
- [ ] 기술 반환 후에도 기술 도감 해제 상태가 유지된다.

## 3. 기술 검증 체크

- [ ] CSV 파싱 오류가 없다.
- [ ] 개별 로더 오류가 없다.
- [ ] 저장소 구성/회귀 검증이 통과한다.
- [ ] Unity Console에 새 오류가 없다.
- [ ] 변경 콘텐츠의 정상/실패/경계 흐름을 확인했다.
- [ ] 새 게임과 기존 저장에서 결과를 확인했다.
- [ ] 기존 대표 콘텐츠 회귀가 없다.

## 4. 인수인계 기록

```text
작업명:
작성자/검토자:
변경 날짜:
변경 파일:
추가/변경/삭제 ID:
참조 영향:
저장 호환성:
자동 검증 결과:
PlayMode 시나리오와 결과:
알려진 제한/후속 작업:
```

## 5. 완료 판정

다음 조건을 모두 만족해야 데이터 작성 완료로 본다.

1. 자동 검증 0 오류
2. 교차 참조 누락 0건
3. 실제 장면의 핵심 사용자 흐름 성공
4. 저장/재로드 결과 확인
5. 수동 검증 한계와 후속 작업 기록
6. 리뷰어가 변경 ID와 영향 범위를 재현 가능
